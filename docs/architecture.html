Deployment architecture

How the AI Digital Twin goes from a git push to a live site, and how a chat message flows once it's running. Everything lives in one AWS account in eu-north-1, defined in Terraform and deployed by GitHub Actions.

1 · What happens on deploy

Triggered by a push to main (deploys dev) or by running the workflow manually and choosing dev, test or prod. Steps run in .github/workflows/deploy.yml → scripts/deploy.sh.

  1. Push to main Or a manual run with an environment chosen. Runs for the same environment queue instead of overlapping.
    GitHub
  2. Log in to AWS via OIDC Actions assumes the role github-actions-twin-deploy. No AWS keys are stored in GitHub.
    GitHub → IAM
  3. Build the Lambda zip uv run deploy.py packages the FastAPI backend into lambda-deployment.zip.
    Runner
  4. terraform init Connects to the state bucket and lock table, then selects the workspace for the environment.
    S3 + DynamoDB
  5. terraform apply Creates or updates about 20 resources: S3, IAM, Lambda, logs, API Gateway, CloudFront.
    AWS
  6. Build & upload frontend The API URL is written into .env.production, then npm run build and aws s3 sync.
    Runner → S3
  7. Invalidate CloudFront Clears the /* cache so visitors get the new files right away.
    CloudFront
The OpenAI key comes from the GitHub secret OPENAI_API_KEY. Terraform receives it as TF_VAR_openai_api_key and passes it to the Lambda as an environment variable.

2 · How a request flows at runtime

The browser loads the static site from CloudFront and sends chat messages directly to API Gateway. Only the Lambda talks to OpenAI.

Managed by Terraform (per environment) External service Client

3 · Environments

The same Terraform code deploys each environment. A Terraform workspace keeps each one's state separate, and the twin-<env>-… prefix keeps resource names from colliding.

dev auto on push

Deployed on every push to main. Resources are named like twin-dev-api.

test

Manual run of Deploy Digital Twin with test selected.

prod

Manual run. Also applies prod.tfvars if it exists, e.g. for a custom domain via Route53 and ACM.

4 · One-time setup (not in this Terraform)

6 · What it costs

While running

Lambda, API Gateway and CloudFront are pay-per-use and stay within the free tier for personal traffic. The main cost is OpenAI usage, which OpenAI bills directly.

After destroy

Only the one-time setup resources remain, at well under $0.01 a month. Log groups are deleted along with the environment.

Custom domain (off)

If enabled, the Route53 hosted zone costs $0.50 a month, plus yearly domain registration. The ACM certificate is free.
